# Nolvion

**AI that belongs to you.**

Nolvion is building a local-first AI environment: one AI system that runs on your own computer, with Nolvion's own models (Tirric), agents and AI teams, memory and tools. Offline by default, with the internet as a switch you control, and extensible through the Nolvion Hub.

**Status:** in development. First early-access wave targeted **November 20, 2026**.

- Join early access: https://nolvion.com
- Building a tool, agent or MCP server? Apply to be a **Founding Hub Creator**: https://github.com/nolvion/early-access/issues/new/choose
- Questions and ideas: https://github.com/nolvion/early-access/discussions

Nolvion's source code and models are not published here. This organization hosts public information, early-access discussion and, later, developer resources for the Nolvion Hub.
